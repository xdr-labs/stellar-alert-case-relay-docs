# Stellar Relay

Stellar Relay는 **Stellar Cyber Alert와 Case**를 polling하고 local SQLite queue/checkpoint를 유지하면서 활성화된 stream을 **NDJSON over TCP**로 전달하는 lightweight Python daemon입니다.

> Option 이름에 historical하게 `syslog`가 포함되어 있지만 실제 wire format은 RFC 5424 Syslog가 아니라 newline-delimited JSON입니다.

## 동작 구조

```mermaid
flowchart LR
    S["Stellar Cyber API"] --> P["Alert / Case Poller"]
    P --> Q["SQLite Queue + Checkpoint"]
    Q --> T["TCP Sender"]
    T --> C["Collector / Parser"]
```

Alert와 Case는 독립적으로 활성화할 수 있습니다.

## 권장 첫 실행

```bash
python3 Stellar_Alert_Case_Syslog.py
```

Wizard가 Credential과 Stream 설정을 수집하고, 선택하면 `stellar-alert-case-syslog.service`를 자동 설치·시작합니다.

자동화와 테스트를 위한 Manual CLI도 계속 지원합니다.
