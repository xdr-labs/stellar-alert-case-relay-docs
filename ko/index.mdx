Stellar Alert & Case Relay는 Stellar Cyber의 Alert와 Case를 가져와 기존 SIEM 또는 SOC 시스템으로 전달하는 경량 Python 데몬입니다.

<Info>
CLI에는 기존 **Syslog** 명칭이 남아 있지만 실제 payload는 **TCP 기반 newline-delimited JSON(NDJSON)** 입니다.
</Info>

```text
Stellar Cyber API
       |
       v
Stellar Alert & Case Relay
       |
       v
SIEM / SOC Receiver
```

## 주요 기능

<CardGroup cols={2}>
  <Card title="Alert 및 Case 전달" icon="arrow-right-arrow-left">
    Alert 전용, Case 전용 또는 두 스트림을 함께 실행할 수 있습니다.
  </Card>
  <Card title="독립적인 전송 대상" icon="route">
    Alert와 Case를 서로 다른 IP와 port로 전송할 수 있습니다.
  </Card>
  <Card title="안정적인 전달" icon="rotate">
    Persistent queue, checkpoint, retry/recovery를 사용합니다.
  </Card>
  <Card title="간단한 운영" icon="server">
    Setup Wizard에서 systemd 설치와 시작까지 자동으로 처리할 수 있습니다.
  </Card>
</CardGroup>
