# Stellar Relay

Stellar Relay는 **Stellar Cyber Alert와 Case**를 주기적으로 조회하고 로컬 SQLite 큐와 체크포인트를 유지하면서 활성화된 데이터를 **NDJSON over TCP**로 전달하는 경량 Python 서비스입니다.

> 일부 기존 옵션 이름에 `syslog`가 남아 있지만 실제 전송 형식은 RFC 5424 Syslog가 아니라 줄 단위 JSON(NDJSON)입니다.

## 동작 구조

```mermaid
flowchart LR
    S["Stellar Cyber API"] --> P["Alert / Case Poller"]
    P --> Q["SQLite Queue + Checkpoint"]
    Q --> T["TCP Sender"]
    T --> C["Collector / Parser"]
```

Alert와 Case는 독립적으로 활성화할 수 있습니다.

## 권장 첫 실행

```bash
python3 Stellar_Alert_Case_Syslog.py
```

마법사가 인증 정보와 전송 설정을 수집하고, 선택하면 `stellar-alert-case-syslog.service`를 자동 설치·시작합니다.

자동화와 테스트를 위한 수동 CLI 실행도 지원합니다.
