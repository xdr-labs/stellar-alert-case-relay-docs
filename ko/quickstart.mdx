최소 하나의 스트림은 필수 설정이 모두 완료되어야 합니다. Alert와 Case 전달은 각각 독립적으로 활성화하거나 함께 실행할 수 있습니다.

## Relay 스크립트 받기

`Stellar_Alert_Case_Syslog.py`는 XDR Labs의 공개 GitHub 저장소에서 관리됩니다.

**소스 저장소:** [xdr-labs/Stellar-Case-Alert-to-Sylog](https://github.com/xdr-labs/Stellar-Case-Alert-to-Sylog)

실행 파일은 저장소 루트에 `Stellar_Alert_Case_Syslog.py`라는 이름으로 있습니다.

### 방법 1: 저장소 전체 Clone

스크립트와 함께 README 및 프로젝트 문서를 같이 받으려면 이 방법을 권장합니다.

```bash
git clone https://github.com/xdr-labs/Stellar-Case-Alert-to-Sylog.git
cd Stellar-Case-Alert-to-Sylog
ls -l Stellar_Alert_Case_Syslog.py
```

### 방법 2: Python 스크립트만 다운로드

Relay 스크립트만 필요한 경우 현재 `main` 버전을 직접 다운로드할 수 있습니다.

```bash
curl -fL \
  -o Stellar_Alert_Case_Syslog.py \
  https://raw.githubusercontent.com/xdr-labs/Stellar-Case-Alert-to-Sylog/main/Stellar_Alert_Case_Syslog.py
```

`wget`을 사용하는 경우:

```bash
wget -O Stellar_Alert_Case_Syslog.py \
  https://raw.githubusercontent.com/xdr-labs/Stellar-Case-Alert-to-Sylog/main/Stellar_Alert_Case_Syslog.py
```

다운로드 후 파일이 정상적으로 존재하는지 확인합니다.

```bash
ls -lh Stellar_Alert_Case_Syslog.py
```

<Note>
  실제 런타임 스크립트의 Source of Truth는 위 GitHub 저장소입니다. 운영 환경을 준비할 때는 기존 서버나 오래된 문서에서 스크립트를 복사하기보다 저장소의 버전을 사용하는 것을 권장합니다.
</Note>

## 시작하기 전에

Relay 호스트에 다음이 준비되어 있는지 확인합니다.

- Python 3
- Stellar Cyber API에 대한 네트워크 접근
- 각 대상 TCP listener에 대한 네트워크 접근
- 런타임 스크립트에서 사용할 수 있는 유효한 Stellar Cyber API 접근 권한
- 위 소스 저장소에서 다운로드한 `Stellar_Alert_Case_Syslog.py`

## Alert만 전달

Alert 전달만 필요한 경우 다음 모드를 사용합니다.

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --alert-interval 60 \
  --alert-syslog-ip 10.10.10.20 \
  --alert-syslog-port 5201
```

Alert 스트림에는 interval, 대상 IP, 대상 port 세 가지 설정이 모두 필요합니다.

## Case만 전달

Case 전용 배포는 다음과 같이 시작할 수 있습니다.

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --case-interval 3600 \
  --case-syslog-ip 10.10.10.20 \
  --case-syslog-port 5142 \
  --case-include-summary \
  --no-case-format-summary \
  --case-fetch-timeout 90
```

Case 스트림에는 interval, 대상 IP, 대상 port가 필요합니다. 위 예제에는 권장되는 Case summary 및 fetch-timeout 옵션도 포함되어 있습니다.

## Alert와 Case를 함께 전달

하나의 프로세스에서 두 스트림을 모두 완전하게 설정합니다.

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --alert-interval 60 \
  --alert-syslog-ip 10.10.10.20 \
  --alert-syslog-port 5201 \
  --case-interval 3600 \
  --case-syslog-ip 10.10.10.20 \
  --case-syslog-port 5142 \
  --case-include-summary \
  --no-case-format-summary \
  --case-fetch-timeout 90
```

Alert와 Case 스트림은 동일한 수신기로 보내거나 서로 다른 대상으로 보낼 수 있습니다.

## 스트림 활성화 규칙

| 스트림 | 필수 설정 |
| --- | --- |
| Alert | `--alert-interval`, `--alert-syslog-ip`, `--alert-syslog-port` |
| Case | `--case-interval`, `--case-syslog-ip`, `--case-syslog-port` |

- 특정 스트림의 모든 옵션을 생략하면 해당 스트림은 비활성화됩니다.
- 스트림 설정을 시작했지만 필수 옵션 중 하나가 빠지면 해당 스트림은 오류로 처리됩니다.
- 최소 하나의 스트림은 필수 설정이 모두 완료되어야 합니다.

## 수신 시스템이 받는 데이터

Relay는 TCP를 통해 newline-delimited JSON(NDJSON)을 전송합니다.

```text
{one JSON object}\n
{next JSON object}\n
...
```

각 JSON 객체는 한 줄을 차지합니다. Alert와 Case 레코드는 출력되는 JSON의 필드를 이용해 구분할 수 있습니다.
