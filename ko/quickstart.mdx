# 빠른 시작

## 1. Script 준비

```bash
git clone https://github.com/xdr-labs/Stellar-Case-Alert-to-Sylog.git
cd Stellar-Case-Alert-to-Sylog
```

Python 3.9+가 필요하며 Python standard library만 사용합니다.

## 2. Setup Wizard 실행

```bash
python3 Stellar_Alert_Case_Syslog.py
```

또는:

```bash
python3 Stellar_Alert_Case_Syslog.py --setup
```

Wizard에서 다음을 설정합니다.

- Stellar Host / User ID / All-Access API Token
- Alert / Case 사용 여부
- 활성화한 Stream의 Interval / Destination IP / TCP Port
- First-run Lookback
- systemd 자동 설치/시작 여부

기본값:

| 항목 | 기본값 |
|---|---:|
| Alert | 활성화 |
| Alert Interval | 60초 |
| Alert Port | 5201 |
| Case | 비활성화 |
| Case Interval | 300초 |
| Case Port | 5202 |
| Initial Lookback | 48시간 |

`--initial-lookback-hours 0`은 최근 1분입니다.

## 3. Service 운영 선택

systemd 질문에 **Yes**를 선택하면 다음 Service를 설치·활성화·시작합니다.

```text
stellar-alert-case-syslog.service
```

확인:

```bash
sudo systemctl status stellar-alert-case-syslog
sudo journalctl -u stellar-alert-case-syslog -n 20 --no-pager
```

## Manual CLI

Token을 shell history에 넣지 않도록 `STELLAR_TOKEN` 사용을 권장합니다.

```bash
export STELLAR_TOKEN='YOUR_TOKEN'

python3 Stellar_Alert_Case_Syslog.py \
  --host YOUR_STELLAR_HOST \
  --userid YOUR_USER_ID \
  --alert-interval 60 \
  --alert-syslog-ip 10.10.10.20 \
  --alert-syslog-port 5201
```

Alert와 Case는 각각 `interval + IP + port` 세 값을 모두 지정해야 활성화됩니다.

전체 option과 Case default는 [설정](/ko/configuration)을 참고하십시오.
