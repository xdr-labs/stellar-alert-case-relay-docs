새 Relay는 대화형 Setup Wizard로 구성하는 것을 권장합니다. 기존 CLI 방식도 그대로 사용할 수 있습니다.

## 1. 다운로드

```bash
curl -fL \
  -o Stellar_Alert_Case_Syslog.py \
  https://raw.githubusercontent.com/xdr-labs/Stellar-Case-Alert-to-Sylog/main/Stellar_Alert_Case_Syslog.py
```

필요한 환경:

- Python 3
- Stellar Cyber API로의 네트워크 연결
- 대상 TCP listener로의 네트워크 연결
- Stellar Cyber User ID와 All-Access API token
- systemd 자동 설치를 사용할 경우 Linux + systemd

## 2. Setup Wizard 실행

```bash
python3 Stellar_Alert_Case_Syslog.py
```

또는:

```bash
python3 Stellar_Alert_Case_Syslog.py --setup
```

Wizard에서 Stellar Cyber host, User ID, API token, 사용할 스트림, 전송 주기, 목적지 IP/port, 최초 lookback을 입력합니다.

| 기본값 | 값 |
| --- | ---: |
| Alert | 활성화 |
| Case | 비활성화 |
| Alert interval | 60초 |
| Case interval | 300초 |
| Alert port | 5201 |
| Case port | 5202 |
| Initial lookback | 48시간 |

Alert와 Case 중 최소 하나는 활성화해야 합니다. Initial lookback `0`은 checkpoint가 없을 때 최근 1분을 의미합니다.

## 3. 실행 방식 선택

마지막 질문:

```text
Run continuously with systemd (auto-start on boot)?
```

일반적인 상시 운영은 **Yes**를 선택합니다. 스크립트가 `stellar-alert-case-syslog.service`를 설치·활성화·시작하고 상태와 최근 로그를 보여줍니다.

**No**를 선택하면 동일 설정의 수동 명령을 출력하고 foreground 실행 여부를 묻습니다.

## 4. 서비스 확인

```bash
sudo systemctl status stellar-alert-case-syslog
sudo journalctl -u stellar-alert-case-syslog -n 20 --no-pager
```

## 수동 CLI 예제

수동 실행에서는 API token을 명령행에 직접 넣지 않도록 `STELLAR_TOKEN` 사용을 권장합니다.

```bash
export STELLAR_TOKEN='YOUR_ALL_ACCESS_TOKEN'
```

### Alert만 전달

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --alert-interval 60 \
  --alert-syslog-ip 10.10.10.20 \
  --alert-syslog-port 5201
```

### Case만 전달

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --case-interval 300 \
  --case-syslog-ip 10.10.10.20 \
  --case-syslog-port 5202
```

### Alert와 Case 함께 전달

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --alert-interval 60 \
  --alert-syslog-ip 10.10.10.20 \
  --alert-syslog-port 5201 \
  --case-interval 300 \
  --case-syslog-ip 10.10.10.20 \
  --case-syslog-port 5202
```
