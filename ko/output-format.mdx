Relay는 **TCP 기반 newline-delimited JSON(NDJSON)** 을 전송합니다.

<Info>
CLI에는 `--alert-syslog-ip` 같은 기존 명칭이 남아 있지만 payload는 RFC 3164/5424 Syslog가 아닙니다.
</Info>

## Framing

한 줄에 JSON 객체 하나가 전달됩니다.

```text
{"...":"..."}\n
{"...":"..."}\n
```

수신 시스템은 각 newline을 레코드 경계로 처리해야 합니다.

## 전송 대상

Alert와 Case는 서로 독립적인 destination을 사용합니다.

```text
Alert: --alert-syslog-ip + --alert-syslog-port
Case:  --case-syslog-ip  + --case-syslog-port
```

두 스트림은 서로 다른 listener 또는 같은 수신 시스템으로 보낼 수 있습니다.

## 수신기 체크리스트

운영 적용 전에 다음을 확인하십시오.

- Relay 호스트에서 TCP listener에 연결 가능
- 각 line을 하나의 JSON 객체로 parsing
- Alert와 Case sample routing 확인
- 실제 출력 기준 SIEM timestamp, source type, field mapping 확인

운영 parser를 확정하기 전에 실제 배포 버전의 대표 이벤트를 수집해 검증하는 것을 권장합니다.
