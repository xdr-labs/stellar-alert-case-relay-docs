# Output Format

Stellar Relay는 **raw TCP connection으로 NDJSON**을 전송합니다.

각 Record는:

- UTF-8 JSON object 하나
- LF(`\n`)로 종료
- 한 줄 단위 전송

예:

```text
{"stellar_record_type":"alert",...}\n
{"stellar_record_type":"case",...}\n
```

Receiver는 line boundary를 유지하고 각 줄을 독립적인 JSON object로 parse해야 합니다.

> Historical CLI option의 `--alert-syslog-*`, `--case-syslog-*` 명칭과 달리 payload는 RFC 5424 Syslog가 아닙니다.

Alert와 Case는 서로 다른 Destination을 사용할 수도 있고 같은 Destination을 공유할 수도 있습니다. 같은 Destination에서는 `stellar_record_type` 같은 JSON field로 구분합니다.

## Receiver Checklist

- Relay Host에서 TCP Listener 접근 가능
- Newline-delimited UTF-8 수신
- 각 Line을 JSON으로 parse
- Configured Port 방화벽 허용
- Retry/Backfill Burst를 처리할 충분한 Receiver Capacity
