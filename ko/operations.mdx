# 운영

## 서비스 상태

```bash
sudo systemctl status stellar-alert-case-syslog
```

## 로그 확인

```bash
sudo journalctl -u stellar-alert-case-syslog -f
```

최근 로그만 확인:

```bash
sudo journalctl -u stellar-alert-case-syslog -n 100 --no-pager
```

## Restart

```bash
sudo systemctl restart stellar-alert-case-syslog
```

## 재설정

Wizard를 다시 실행합니다.

```bash
python3 Stellar_Alert_Case_Syslog.py --setup
```

적용 전 Summary를 확인하십시오.

## 설치 파일

```text
/usr/local/lib/stellar-alert-case/Stellar_Alert_Case_Syslog.py
/etc/default/stellar-alert-case-syslog
/etc/systemd/system/stellar-alert-case-syslog.service
```

Token environment file은 root-only 권한으로 저장됩니다.

## 실행 상태

기본 경로:

```text
~/.local/state/stellar_alert_case/
├── queue.db
├── logs/
└── stellar_alert_case.lock
```

같은 상태 디렉터리를 사용하는 여러 인스턴스를 동시에 실행하지 마십시오.

## Backfill

`--backfill DAYS`는 과거 데이터를 다시 조회해 재전송할 수 있습니다. 테스트/복구 목적으로만 사용하십시오.
