---
title: "Quickstart"
description: "Download, configure, and start Stellar Alert & Case Relay."
---

The recommended setup method is the interactive wizard. Manual CLI operation remains available.

## 1. Download

```bash
curl -fL \
  -o Stellar_Alert_Case_Syslog.py \
  https://raw.githubusercontent.com/xdr-labs/Stellar-Case-Alert-to-Sylog/main/Stellar_Alert_Case_Syslog.py
```

Requirements:

- Python 3
- Network access to the Stellar Cyber API
- Network access to the destination TCP listener
- Stellar Cyber User ID and All-Access API token
- Linux with systemd for automatic service installation

## 2. Run the setup wizard

```bash
python3 Stellar_Alert_Case_Syslog.py
```

You can also run:

```bash
python3 Stellar_Alert_Case_Syslog.py --setup
```

The wizard asks for the Stellar Cyber host, User ID, API token, enabled streams, forwarding intervals, destination IP/ports, and initial lookback.

| Default | Value |
| --- | ---: |
| Alert | Enabled |
| Case | Disabled |
| Alert interval | 60 seconds |
| Case interval | 300 seconds |
| Alert port | 5201 |
| Case port | 5202 |
| Initial lookback | 48 hours |

At least one stream must be enabled. Initial lookback `0` means the last 1 minute when no checkpoint exists.

## 3. Choose how to run

At the end of setup:

```text
Run continuously with systemd (auto-start on boot)?
```

Choose **Yes** for normal continuous operation. The script installs, enables, and starts `stellar-alert-case-syslog.service`, then shows its status and recent logs.

Choose **No** to see the equivalent manual command and optionally run in the foreground.

## 4. Verify the service

```bash
sudo systemctl status stellar-alert-case-syslog
sudo journalctl -u stellar-alert-case-syslog -n 20 --no-pager
```

## Manual CLI examples

For manual runs, use `STELLAR_TOKEN` so the API token is not placed directly in the command line:

```bash
export STELLAR_TOKEN='YOUR_ALL_ACCESS_TOKEN'
```

### Alert only

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --alert-interval 60 \
  --alert-syslog-ip 10.10.10.20 \
  --alert-syslog-port 5201
```

### Case only

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --case-interval 300 \
  --case-syslog-ip 10.10.10.20 \
  --case-syslog-port 5202
```

### Alert and Case

```bash
python3 Stellar_Alert_Case_Syslog.py \
  --alert-interval 60 \
  --alert-syslog-ip 10.10.10.20 \
  --alert-syslog-port 5201 \
  --case-interval 300 \
  --case-syslog-ip 10.10.10.20 \
  --case-syslog-port 5202
```
