# Quickstart

## 1. Get the script

```bash
git clone https://github.com/xdr-labs/Stellar-Case-Alert-to-Sylog.git
cd Stellar-Case-Alert-to-Sylog
```

Python 3.9+ is required. The daemon uses the Python standard library only.

## 2. Run the setup wizard

```bash
python3 Stellar_Alert_Case_Syslog.py
```

or:

```bash
python3 Stellar_Alert_Case_Syslog.py --setup
```

The wizard asks for:

- Stellar host, user ID, and All-Access API token
- Alert and/or Case forwarding
- interval, destination IP, and TCP port for each enabled stream
- first-run lookback
- whether to install and start systemd automatically

Default values:

| Setting | Default |
|---|---:|
| Alert | enabled |
| Alert interval | 60 sec |
| Alert port | 5201 |
| Case | disabled |
| Case interval | 300 sec |
| Case port | 5202 |
| Initial lookback | 48 hours |

`--initial-lookback-hours 0` means the most recent 1 minute.

## 3. Choose service operation

Answer **Yes** to the systemd question to install, enable, and start:

```text
stellar-alert-case-syslog.service
```

Verify:

```bash
sudo systemctl status stellar-alert-case-syslog
sudo journalctl -u stellar-alert-case-syslog -n 20 --no-pager
```

## Manual CLI

Use `STELLAR_TOKEN` instead of embedding the token in shell history:

```bash
export STELLAR_TOKEN='YOUR_TOKEN'

python3 Stellar_Alert_Case_Syslog.py \
  --host YOUR_STELLAR_HOST \
  --userid YOUR_USER_ID \
  --alert-interval 60 \
  --alert-syslog-ip 10.10.10.20 \
  --alert-syslog-port 5201
```

Alert and Case each require a complete `interval + IP + port` set.

For all options and Case defaults, see [Configuration](/configuration).
