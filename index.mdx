# Stellar Relay

Stellar Relay is a lightweight Python daemon that polls **Stellar Cyber Alerts and Cases**, keeps durable local queue/checkpoint state, and forwards enabled streams as **NDJSON over TCP**.

> Historical option names contain "syslog", but the wire format is newline-delimited JSON, not RFC 5424 syslog text.

## How it works

```mermaid
flowchart LR
    S["Stellar Cyber API"] --> P["Alert / Case Pollers"]
    P --> Q["SQLite Queue + Checkpoints"]
    Q --> T["TCP Sender"]
    T --> C["Collector / Parser"]
```

Alert and Case streams are independent. Run Alert only, Case only, or both.

## Recommended first run

```bash
python3 Stellar_Alert_Case_Syslog.py
```

The wizard collects credentials and stream settings, then can install and start `stellar-alert-case-syslog.service` automatically.

Manual CLI operation remains available for automation and testing.
