---
title: "Stellar Alert & Case Relay"
description: "Forward Stellar Cyber alerts and cases into existing SIEM and SOC workflows."
---

Stellar Alert & Case Relay is a lightweight Python daemon that retrieves Stellar Cyber alerts and cases and forwards them to an existing SIEM or SOC system.

<Info>
The CLI keeps the historical **Syslog** option names, but the payload is **newline-delimited JSON (NDJSON) over TCP**.
</Info>

```text
Stellar Cyber API
       |
       v
Stellar Alert & Case Relay
       |
       v
SIEM / SOC Receiver
```

## Key features

<CardGroup cols={2}>
  <Card title="Alert and Case forwarding" icon="arrow-right-arrow-left">
    Run Alert-only, Case-only, or both streams.
  </Card>
  <Card title="Independent destinations" icon="route">
    Send Alert and Case data to separate IP addresses and ports.
  </Card>
  <Card title="Reliable delivery" icon="rotate">
    Uses persistent queues, checkpoints, and retry/recovery.
  </Card>
  <Card title="Simple operation" icon="server">
    Interactive setup can install and start the systemd service automatically.
  </Card>
</CardGroup>
