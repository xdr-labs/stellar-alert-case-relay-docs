# Surface Reconciliation Contract

Public surface: https://stellar-relay.xdr.ooo

Before a user-facing documentation release is accepted, drive the exact candidate with a real Chromium/Chrome process and reconcile the rendered public site against the committed navigation/content.

Required PASS evidence:
- the public root loads without an application/rendering error;
- primary navigation exposes the documented mission path: overview / quickstart / configuration / operations / troubleshooting;
- at least one English/Korean route is exercised when both languages are published;
- internal links used by the primary mission do not resolve to a 404/error page;
- rendered titles/navigation correspond to the exact candidate being qualified.

Static JSON/MDX parsing or CI alone is not execution PASS.
